FileBridge macOS 版安装与使用说明
==================================

版本：macOS v5.2（服务端内部 v4.2，与 Windows 版功能界面完全一致）
适用：Apple 芯片（M1/M2/M3…）选"Apple芯片"包；Intel 芯片选"Intel芯片"包。

----------------------------------------
一、安装（三步）
----------------------------------------
1. 解压 zip，得到 FileBridge.app；
2. 把 FileBridge.app 拖入"应用程序"文件夹（或直接双击运行）；
3. 首次运行：如果提示"无法打开，因为来自身份不明的开发者"：
   右键（或按住 Control 点击）FileBridge.app → 打开 → 确认打开。
   也可以在 系统设置 → 隐私与安全性 → 底部"仍要打开"。
   （这是 macOS 对未签名个人软件的常规提示，FileBridge 是自研工具，
   完成上述操作后即可正常使用，后续打开不再提示。）

----------------------------------------
二、首次使用（配置）
----------------------------------------
启动后自动打开设置窗口（如未出现，点菜单栏 FileBridge 图标 → 打开设置面板）。
1. 共享目录：一行一个文件夹路径，例如：
   /Users/你的用户名/照片
   /Users/你的用户名/Documents
2. 用户名 / 密码：设置手机端连接账号（密码至少 4 位）；
3. 开机自启：点"开启"——之后 Mac 重启自动运行 FileBridge 服务（launchd 方式）；
4. Tailscale 组网：需要外网访问时点"登录组网"，用账号授权一次。

配置保存在 ~/.filebridge/（换版本自动沿用）。

----------------------------------------
三、日常使用
----------------------------------------
- 关窗 = 最小化到菜单栏图标，服务继续后台运行；
- 菜单栏图标（右上角）：打开设置面板 / 退出（停止服务）；
- 点击 Dock 图标可随时唤出窗口。

----------------------------------------
四、手机端配套（与 Windows 版完全相同）
----------------------------------------
- 手机安装 FileBridge APK（安卓）→ 添加服务器：
  地址填 Mac 的 Tailscale 组网 IP（100.120.x.x，设置页可查）或局域网 IP，
  端口 8123，账号密码填上面配置的；
- 浏览 / 预览 / 下载 / 上传 / 图片视频翻页等操作与 Windows 版一致，
  详细操作见《使用说明.txt》的"手机端"章节。

----------------------------------------
五、常见问题
----------------------------------------
Q：双击打不开 / 提示身份不明的开发者？
A：按上面"首次运行"的方法打开一次即可。

Q：开机自启不生效？
A：设置页点"开启"后重启 Mac 验证；
   也可手动确认 ~/Library/LaunchAgents/com.filebridge.server.plist 是否存在。

Q：外网连不上？
A：① 设置页确认组网显示"已连接"和 100.x.x.x 地址；
   ② 手机 Tailscale 与 Mac 登录同一账号并开启连接；
   ③ 地址端口、账号密码核对。

Q：防火墙提示？
A：macOS 首次启动服务可能弹"允许 FileBridge 接受传入连接"，选择"允许"。
