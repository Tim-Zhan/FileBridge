信鸽（PigeonFile）使用说明（电脑端 + 手机端）
========================================

当前版本：电脑端服务 v7.0（安装包 v7.0）｜手机端 v2.4
适用场景：手机随时访问电脑里的文件（浏览、搜索、预览、下载、上传），像操作本地文件一样。

----------------------------------------
一、这个软件是干什么的
----------------------------------------
- 电脑上装「信鸽」服务端，把想共享的文件夹（可以多个）开放出来；
- 手机装「信鸽」客户端，通过 Tailscale 组网（外网也能连）或同一 WiFi 访问；
- 打开文件走手机自带的软件（相册、WPS、PDF 阅读器等），不需要在 App 里内置播放器；
- 特点：电脑配置一次后开机自启、无需每次手动开；不向公网开放端口，靠 Tailscale 加密组网；
- 名字来历：「飞鸽传书」——把电脑上的文件，像信鸽一样送到你的掌上。

----------------------------------------
二、电脑端
----------------------------------------
【1. 安装】
两种方式任选：
- 安装版：双击 PigeonFile-Setup-Windows-v7.0.exe → 确认 → 自动装到
  C:\Users\你的用户名\AppData\Local\PigeonFile，自动创建桌面和开始菜单快捷方式，
  装完自动启动；可在"控制面板 → 程序和功能"中卸载。
- 便携版：解压 PigeonFile-Windows-v7.0.zip，进入"PigeonFile-桌面版"文件夹，
  双击 PigeonFile.exe 启动。整个文件夹可拷贝到别的电脑。

【2. 首次使用（配置）】
启动后会自动打开设置页（如果没有，可从右下角托盘图标 → "打开设置面板"）。
首次使用需设置：
- 共享目录：一行一个文件夹路径，例如
  D:\照片
  D:\工作文档
  E:\学习资料
  点"保存"后，手机端最外层会看到这几个共享目录。
  （提示：请共享自己创建的文件夹；共享整个 C 盘也能浏览，
   但 C 盘下 Windows 等系统目录受系统权限保护，普通权限进不去，属正常现象。）
- 用户名 / 密码：设置手机端连接用的账号（密码至少 4 位）。
- 开机自启：点"开启"，以后电脑重启后服务自动在后台运行，无需手动打开。
- Tailscale 组网：如果要从外网访问，在设置页点"登录组网"，按提示完成授权。

【3. 设置页里能做什么】
- 查看/修改共享目录（可多个）
- 修改用户名、密码
- 开关开机自启
- 查看 Tailscale 组网状态（组网 IP 类似 100.120.x.x，手机连接要用它）
- 显示当前版本号（v7.0）

【4. 日常使用】
- 关闭窗口 = 最小化到托盘，服务继续在后台运行；
- 托盘图标右键：打开设置面板 / 退出（退出会停止服务）；
- 想彻底停止服务时选"退出（停止服务）"，不是直接关窗口。

【5. 文件与配置存放位置】
- 配置文件：C:\Users\你的用户名\.filebridge\filebridge-config.json
- 组网状态：C:\Users\你的用户名\.filebridge\tsnet-state（换新版本时保留此目录可免重新授权）
- 桌面端日志：C:\Users\你的用户名\.filebridge\desktop.log（排障用）

----------------------------------------
三、手机端（安卓）
----------------------------------------
【1. 联网准备】
- 信鸽 App 内置了官方 Tailscale 安装包：
  - 手机没装 Tailscale → App 顶部状态条点【安装】，一键装官方 App；
  - 已安装 → 点状态条直接【跳转】Tailscale 登录/连接；
  - 状态条实时显示「组网：已开启 / 未开启」。
- 外网访问：手机与电脑登录【同一个 Tailscale 账号】并开启组网，
  手机所有软件（含系统播放器、WPS）都能直接访问电脑；
- 局域网访问：手机和电脑连同一个 WiFi 也行（用电脑的局域网 IP），无需组网。

【2. 添加服务器】
打开信鸽 App → 顶部组网状态条（未装 Tailscale 时先点「安装」）；
右上角"＋"添加服务器：
- 名称：随便起（如"家里电脑"）
- 地址：填电脑的 Tailscale 组网 IP（100.120.x.x）或局域网 IP，端口 8123
  （形如 http://100.120.238.93:8123）
- 用户名 / 密码：填电脑端设置页里配置的账号
- 保存后点进去即可浏览。

【3. 浏览文件】
- 最外层是共享目录列表（配置了几个就显示几个）；
- 点进目录逐层浏览，文件夹在前；
- 右上角菜单：
  - 放大镜【搜索】：输入文件名，跨目录递归搜索整个电脑（最多 300 条），
    每条结果标注所在路径，点文件直接打开、点文件夹直接跳进去；
  - ⋮【排序】：按「名称」或「修改时间」排序，一键切换，文件夹永远排最前；
  - 上传：列表底部「➕ 上传文件到此目录」。
- 图片类文件在列表里直接显示缩略图。

【4. 打开文件】
- 单击文件 = 预览：图片/视频在 App 内查看（图片可左右滑动翻页、双击放大拖动），
  其它文件（Word/PDF/Excel 等）会交给手机自带的软件打开；
- 长按文件 = 菜单：预览 / 用其他应用打开 / 下载到…；
- "用其他应用打开"走系统选择器，可勾选"总是用此应用打开此类文件"，
  以后同类文件直接一键打开，不用再选。

【5. 预览与缓存】
- 预览文件会缓存到 App 缓存目录，方便快速反复查看；
- 缓存不常驻：打开 App 时自动清理超过 24 小时的缓存；
- 退出 App 时自动清理超过 30 分钟的缓存；
- 想彻底清空：手机设置 → 应用 → 信鸽 → 清除缓存。

【6. 下载文件】
- 长按文件 → "下载到…"，选择手机上的保存位置（系统文件管理器）；
- 大文件下载支持断点续传（服务端支持 Range）。

【7. 上传文件】
- 进入任意文件夹，把列表翻到最底部，点"➕ 上传文件到此目录"；
- 在手机文件选择器里选文件（可多选）→ 自动传到当前文件夹；
- 注意：在最外层（共享目录列表页）没有上传入口，先进某个共享目录再传。

【8. 图片 / 视频查看】
- 点开图片或视频后，左右滑动切换上一张/下一个；
- 图片双击放大/缩小、拖动查看细节；
- 视频用内置播放器播放，可横屏、拖动进度。

【9. 多共享目录】
- 电脑配置了多个共享目录时，手机端最外层会全部列出；
- 上传、浏览都按目录区分，互不干扰。

----------------------------------------
四、Tailscale 组网 IP 使用方法（外网访问）
----------------------------------------
【Tailscale 是什么】
一个加密组网工具：把电脑和手机拉进同一个"虚拟局域网"，
电脑会获得一个专属组网 IP（形如 100.120.x.x）。
手机在任何一个网络（家里的 WiFi、外面的 4G/5G、公司网络）里，
只要连上组网，就能用这个 IP 直接访问电脑，不需要公网端口、不需要路由器设置。

【第一步：电脑端开启组网（只需一次）】
1. 打开电脑端设置页（托盘 → 打开设置面板）；
2. 点"登录组网"按钮，浏览器会弹出 Tailscale 授权页；
3. 用你的账号登录授权（支持谷歌、微软、邮箱等账号）；
4. 回到设置页点"刷新状态"，看到"已连接"和组网 IP（100.120.x.x）即成功；
5. 这台电脑从此归到你的账号名下，重启电脑后自动恢复连接，无需再操作。

【第二步：手机端组网】
1. 打开信鸽 App，顶部状态条：
   - 未装 Tailscale → 点【安装】，从内置包一键安装官方 App；
   - 已安装 → 点状态条跳转到 Tailscale App；
2. 用【和电脑同一个账号】登录并开启组网（系统弹 VPN 授权，点"确定"）；
3. 返回信鸽，状态条显示「组网：已开启」即成功；
   之后手机所有软件都能访问组网地址（100.x.x.x），无需再操作。

【第三步：手机信鸽里填组网 IP】
1. 手机端添加/编辑服务器时，地址填电脑端设置页显示的组网 IP，
   端口保持 8123，形如：
   http://100.120.238.93:8123
2. 用户名/密码仍填电脑端配置的账号；
3. 保存后即可在任何网络访问电脑文件。

【关键使用要点】
- 用组网 IP 时，手机需保持 Tailscale 组网开启（状态条显示"已开启"）；
- 手机和电脑【必须是同一个 Tailscale 账号】才能互通；
- 组网 IP 一般长期不变；电脑端设置页可随时查看/刷新；
- 手机重启后，打开信鸽状态条确认组网仍开启即可；
- 同一账号下加新设备（手机、平板、另一台电脑）会自动互相可见；
- 不想走外网时，同一 WiFi 下直接用电脑局域网 IP（如 192.168.1.x）也行，
  此时不用登录组网；
- 断开组网：到 Tailscale App 里关闭连接即可。

【常见问题】
Q：手机组网已开启，但信鸽连不上？
A：① 电脑端设置页确认组网也是"已连接"且账号一致；
   ② 电脑端服务在运行（托盘图标在）；
   ③ 地址端口核对无误（http://100.x.x.x:8123）；
   ④ 用户名/密码正确。

Q：电脑端设置页看不到组网 IP？
A：点"登录组网"完成一次授权；刷新状态等待 10 秒左右；
   若一直不出现，检查电脑能否正常上网。

Q：换电脑 / 想移除设备？
A：登录 Tailscale 官网（login.tailscale.com）的管理后台，
   在设备列表里删除旧设备即可；重新登录后新电脑会拿到新 IP。

----------------------------------------
五、常见问题
----------------------------------------
【手机连不上 / 显示"无法连接服务器"】
1. 先确认电脑端服务在运行（托盘图标在）；
2. 确认地址端口正确（http://IP:8123）；
3. 外网连接确认手机组网"已开启"、电脑组网"已连接"且同一账号；
4. 检查用户名密码是否正确；
5. 看电脑端桌面日志 desktop.log，或设置页是否正常显示。

【点进某个文件夹提示"没有权限"】
正常现象：Windows 系统目录（如 C 盘下的 Windows、Program Files 等）
受 NTFS 权限保护，普通权限进不去；
建议共享自己创建的文件夹（如 D 盘个人目录），不要依赖共享整个 C 盘。

【杀毒软件报毒 / 拦截】
信鸽是个人开源工具，无任何恶意行为。被 360 等拦截多为误报，原因：
- 个人项目没有商业代码签名证书，杀软对"无签名新程序"天然警惕；
- 安装包是自解压结构（可执行程序 + 尾部数据），是启发式扫描重点；
- 服务端要开机自启 + 监听端口 + 建 VPN 网卡，行为组合像"远控"，实际是你自己的文件服务；
- 云查杀对新文件无信誉，容易先报后放行。
处理方式：
1. 在杀毒软件中把信鸽文件夹加入信任区/白名单；
2. 恢复被隔离的文件后再启动；
3. 源码全部公开（GitHub 仓库 server/ desktop/ installer/ android/ 四个目录），
   可逐行审阅；也可以在电脑上自己编译服务端（cd server && go build）。

【换新版本要重配吗】
不用。配置在 C:\Users\你的用户名\.filebridge 下，
新版本会自动读取；Tailscale 授权也保留。

【忘记密码 / 想改密码】
电脑端设置页修改用户名密码后，手机端服务器列表里对应更新即可。

【端口和安全性】
服务监听 8123 端口，只通过 Tailscale 组网和局域网访问，
不对公网开放端口；访问需要用户名密码鉴权。
