信鸽（PigeonFile）macOS 使用说明
================================

当前版本：电脑端服务 v7.0｜手机端 v2.4

----------------------------------------
一、安装
----------------------------------------
1. 下载对应芯片的安装包：
   - Apple 芯片（M1/M2/M3/M4）：PigeonFile-macOS-Apple-Silicon-v7.0.zip
   - Intel 芯片：PigeonFile-macOS-Intel-v7.0.zip
   不确定芯片型号：左上角  → 关于本机 → 芯片 一栏会写明。
2. 解压 zip，把 PigeonFile.app 拖入「应用程序」文件夹。
3. 首次打开：右键 PigeonFile.app → 打开（跳过"未验证的开发者"提示）。
   若提示"无法验证开发者"，到 系统设置 → 隐私与安全性 → 仍要打开。

----------------------------------------
二、首次使用（配置）
----------------------------------------
1. 打开 PigeonFile.app，会自动打开设置页（也可从菜单栏托盘图标进入）；
2. 设置：
   - 共享目录：一行一个文件夹路径，例如
     /Users/你的名字/照片
     /Users/你的名字/文档
   - 用户名 / 密码：手机端连接用的账号（密码至少 4 位）
   - 开机自启：点"开启"（使用 launchd，重启后自动运行）
   - Tailscale 组网：要从外网访问时点"登录组网"，浏览器授权一次即可
3. 设置页会显示本机局域网 IP 和组网 IP（100.x.x.x）、版本号（v7.0）。

----------------------------------------
三、手机端连接
----------------------------------------
1. 手机装「信鸽」APK；
2. 顶部组网状态条：未装 Tailscale 点【安装】（内置官方安装包），
   已装则点状态条跳转登录，与电脑用同一个账号，开启组网；
3. 添加服务器：名称随意，地址填电脑的组网 IP 或局域网 IP，
   端口 8123，用户名/密码与电脑一致；
4. 之后即可浏览、搜索、预览、下载、上传电脑文件。

----------------------------------------
四、日常使用与排障
----------------------------------------
- 关闭窗口 = 菜单栏托盘继续运行；退出请用托盘菜单"退出（停止服务）"；
- 配置文件：~/.filebridge/filebridge-config.json；
  组网状态：~/.filebridge/tsnet-state（换版本保留此目录可免重新授权）；
  日志：~/.filebridge/desktop.log；
- 手机连不上：确认服务在运行、地址端口正确、组网已开且同一账号、账号密码正确；
- 杀软/系统安全提示：个人开源项目无签名证书属正常误报，源码全公开可审阅，
  加入信任即可；也可以自己编译（cd server && go build）。
